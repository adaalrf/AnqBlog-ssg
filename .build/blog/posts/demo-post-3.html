Performance and Architecture

AnqBlog-ssg is built for speed. Build times average under 2 seconds, and the output is optimized static files.

Build Process

The generator uses template caching to minimize file reads. Markdown is processed once, templates are reused, and the result is pure static HTML.

Output

Every page is pre-rendered. No server-side rendering, no database queries, no runtime overhead. Just HTML, CSS, and JavaScript.

Deployment

Deploy to any static host:

  • GitHub Pages
  • Netlify
  • Vercel
  • Traditional web servers
  • CDNs

The public/ directory contains everything you need. No build step required on the server.

Performance and Architecture

AnqBlog-ssg is built for speed. Build times average under 2 seconds, and the output is optimized static files.

Build Process

The generator uses template caching to minimize file reads. Markdown is processed once, templates are reused, and the result is pure static HTML.

Output

Every page is pre-rendered. No server-side rendering, no database queries, no runtime overhead. Just HTML, CSS, and JavaScript.

Deployment

Deploy to any static host:

  • GitHub Pages
  • Netlify
  • Vercel
  • Traditional web servers
  • CDNs

The public/ directory contains everything you need. No build step required on the server.
