Getting Started with AnqBlog-ssg

AnqBlog-ssg is a static site generator that converts Markdown to HTML. Build once, serve anywhere—no Node.js required on your web server.

Why Static?

Static sites are fast, secure, and cheap to host. They work on any web server, from a Raspberry Pi to a CDN. Perfect for blogs, documentation, or portfolios.

Creating Your First Post

Create a Markdown file in src/content/blog/posts/ with front matter:

---\ntitle: My First Post\ndate: 03.01.2026\ntags: [web-dev, static-sites]\n---\n\n# My First Post\n\nWrite your content in Markdown here...\n

Run npm run build and your post is ready in the public/ directory.

What's Next?

  • Customize templates in src/templates/
  • Adjust styling in tailwind.config.js
  • Configure site settings in scripts/config.js

The generated site is pure HTML, CSS, and JavaScript—ready to deploy anywhere.
