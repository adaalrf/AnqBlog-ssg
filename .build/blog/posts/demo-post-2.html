Customization Guide

Tailor AnqBlog-ssg to match your style. Everything is configurable.

Templates

Templates in src/templates/ control your site's structure. Modify layout-template.html for the main layout, or create page-specific templates.

Styling

Built on Tailwind CSS. Customize the design system in tailwind.config.js and add custom styles in src/styles/tailwind.css.

Configuration

Edit scripts/config.js to set:

  • Site name
  • Posts per page
  • Directory paths

Content Structure

Organize posts with tags, set dates in DD.MM.YYYY format, and use front matter for metadata. The generator handles pagination and tag pages automatically.

Customization Guide

Tailor AnqBlog-ssg to match your style. Everything is configurable.

Templates

Templates in src/templates/ control your site's structure. Modify layout-template.html for the main layout, or create page-specific templates.

Styling

Built on Tailwind CSS. Customize the design system in tailwind.config.js and add custom styles in src/styles/tailwind.css.

Configuration

Edit scripts/config.js to set:

  • Site name
  • Posts per page
  • Directory paths

Content Structure

Organize posts with tags, set dates in DD.MM.YYYY format, and use front matter for metadata. The generator handles pagination and tag pages automatically.
